# P6 teaser

Statická stránka pripravovaného rezidenčného projektu P6 v Bratislave. Čisté HTML, CSS a JavaScript, bez buildu.

- Jazyky: slovenčina, angličtina, nemčina. Texty prekladov sú v `assets/js/i18n.js`, výber jazyka v `assets/js/lang-detect.js`.
- Údaje prevádzkovateľa a ID meracích nástrojov sa dopĺňajú v `assets/js/config.js`.
- Cookie súhlas je v `assets/js/consent.js`. Bez súhlasu sa nenačíta nič od tretích strán.

Lokálne spustenie:

```bash
python3 -m http.server 4173
```
